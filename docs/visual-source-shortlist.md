# Visual source shortlist

First-pass research, 2026-10-20. No assets imported or integrated. The user is open to all art styles and prioritizes reusing visuals and selected systems from ordinary games, not only educational games.

| Direction | Source | Available material and limitations |
| --- | --- | --- |
| Compact pixel-art adventure | [Kenney Tiny Dungeon](https://kenney-assets.itch.io/tiny-dungeon), [Tiny Town](https://kenney.nl/assets/tiny-town) | CC0. Dungeon pack includes characters, weapons, items, environment tiles, and a Tiled sample map; Town supplies overworld/town tiles. These are art packs, not complete animated combat systems. |
| Stylized 3D fantasy | [KayKit Adventurers](https://kaylousberg.itch.io/kaykit-adventurers) | Free standard pack includes five rigged characters and accessories, with basic animations; additional free animation pack linked by the author. CC0. Extra characters and editable Blender source are paid tiers. Requires 3D rendering and animation integration. |
| Illustrated fantasy and tactical sprites | [Battle for Wesnoth source](https://github.com/wesnoth/wesnoth), [official artwork guidance](https://wiki.wesnoth.org/Create_art) | Candidate source for portraits, units, and environments from an existing game. [Official policy](https://wiki.wesnoth.org/Wesnoth:Copyrights) assigns core visual/audio assets GPL v2-or-later or CC BY-SA 4.0; exact file licenses must be checked. Do not assume add-on artwork has identical terms. |
| Adventure interface components | [Kenney UI Pack - Adventure](https://kenney.nl/assets/ui-pack-adventure) | 130 CC0 interface assets, including button/panel/slider categories. Useful independently of the chosen game engine; visual compatibility still needs comparison. |

## Evaluation approach

Compare actual previews for a complete scene: character, enemy, environment, combat effects, and UI. Prefer a source family that supplies most of those elements, then add compatible pieces from other sources. This is an engineering recommendation, not a user decision to choose one style.

The game-foundation research in game-source-research.md remains background material; engine selection should not constrain this visual search prematurely.
