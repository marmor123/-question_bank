# Question Bank RPG

A separate, offline-first study game built around medical question practice.
This repository currently captures the game design and planning configuration.
The game engine, visual style, and reusable game components have not been selected.

## Planning destination

A build-ready plan for the first playable adventure, with reusable visual sources,
a technical foundation, and a question-to-combat experience evaluated by the user.
Production implementation follows that planning effort.

## Project documentation

- [Game design](docs/game-design.md): agreed behavior, unresolved decisions, and provisional choices.
- [Domain glossary](CONTEXT.md): shared terminology.
- [Visual source shortlist](docs/visual-source-shortlist.md): candidate art sources.
- [Game foundation research](docs/game-source-research.md): preliminary codebase research, not an adoption decision.
- [Agent instructions](AGENTS.md): engineering skills configuration.

Track decision maps and tickets in [GitHub Issues](https://github.com/marmor123/-question_bank/issues).
The active map is [Plan the first playable study RPG adventure](https://github.com/marmor123/-question_bank/issues/1).
Its child issues and native dependencies show which decisions can be worked next.
Existing study-app progress is not imported into the game. Local question datasets,
source PDFs, generated outputs, and credentials are excluded from version control.

## Development status

There is no game build or test command yet. The initial repository commit contains
planning documents and configuration only; the existing local study application
has not been imported as the game's implementation.
